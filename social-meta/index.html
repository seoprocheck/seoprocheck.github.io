Control how your links look when shared

When someone shares your page on Facebook, LinkedIn or X, the title, description and image come from tags in your page head. If those tags are missing, the platform picks something on its own, which may not be the text or image you would choose. These four tools write those tags and show you a preview before you publish.

Which tool for which job

  • Open Graph Generator: write the og: tags that Facebook, LinkedIn and other apps read, including a share image (the tool suggests 1200 by 630 pixels).
  • Twitter Card Generator: choose a summary card or a large image card for X and add your @username.
  • Meta Tags Generator: produce a starter head block with charset, viewport, title, description, canonical and robots tags.
  • Social Media Preview: see a mockup of your link on Facebook, LinkedIn and X as you type.

For the search result itself, use the SERP Preview Tool in Content Analysis. The previews are mockups, not screenshots, and platforms cache link previews, so after you change your tags, ask the platform to fetch the page again with its own tool, such as Facebook's Sharing Debugger. In the Meta Tags Generator, pick a noindex robots option for any page you want kept out of search. Google has said it does not use the keywords meta tag, so you can leave that field empty.

For how to write the title and description these tags carry, read Title Tags and Meta Descriptions: The Complete Guide.
