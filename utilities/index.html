Small tools for everyday SEO and web work

These nine utilities handle the quick conversions and checks that come up while you edit pages, set up tracking or read data: encoding a URL, formatting JSON, testing a pattern, turning a title into a slug. They run in your browser, so you can paste client data or unreleased URLs without sending them anywhere.

Which tool for which job

  • JSON Validator & Formatter: check that JSON parses, then format or minify it. To check JSON-LD, paste it without its script tags.
  • Regex Tester: try a pattern with the g, i and m flags and see every match highlighted.
  • UTM Parameter Builder: add source, medium, campaign, term and content tags to a link for your analytics.
  • URL Slug Generator: turn a title into a lowercase, hyphenated slug.
  • URL Encoder/Decoder: read or build links and query strings that contain spaces or symbols.
  • Timestamp Converter: switch between Unix timestamps and dates, with ISO 8601, UTC and local time shown.
  • HTML Entity Converter, Base64 Encoder/Decoder and Lorem Ipsum Generator: escape special characters, decode Base64 strings and fill mockups with placeholder text.

The Regex Tester uses your browser's JavaScript engine. Google Search Console filters use RE2 syntax, which has no lookaheads or backreferences, so a pattern that works here may fail there. The slug generator turns accented letters into plain ones and underscores into hyphens, so café becomes cafe, but it drops other symbols, so check that names such as Q&A still read well. In UTM tags, keep values lowercase and consistent, since Google Analytics treats Email and email as separate values.

For patterns you can use on your own query data, read Using Regex in Google Search Console to Find Hidden Query Opportunities.
