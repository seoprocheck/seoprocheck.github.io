Video Schema Generator

What it does

This tool writes VideoObject structured data for one video. It takes a title, description, thumbnail URL, video file URL, an optional embed URL, upload date and duration, and returns a JSON-LD block wrapped in a <script type="application/ld+json"> tag. Any field you leave blank is dropped from the output. The page does not fetch your video or thumbnail, so it cannot tell whether the URLs work; it only formats what you type, locally in your browser.

How to use it

  1. Enter the Video Title and a Description that match what viewers see on the page.
  2. Paste the full Thumbnail URL of an image Google can crawl.
  3. Paste the address of the media file itself into Video file URL (contentUrl), and the player address into Embed URL if you have one.
  4. Pick the Upload Date and type the Duration in ISO 8601 form, for example PT5M30S for five minutes thirty seconds or PT1H2M for an hour and two minutes.
  5. Click Generate Schema, then Copy JSON-LD, and paste the block into the page that hosts the video.

Get the URLs and the date right

The two URL fields map to properties that mean different things: contentUrl should point at the actual media file (an .mp4, for example), and embedUrl at a player. A YouTube or Vimeo link is a player, not a file, so put it in Embed URL and leave the file field empty. If you host the file yourself, you can fill both.

The date picker gives you a date with no time or time zone. Google's video documentation asks for uploadDate in ISO 8601 and recommends including time zone information, so you may want to extend it to something like 2026-09-21T08:00:00-05:00. Google lists name, thumbnailUrl and uploadDate as required, so fill those three at minimum. Duration is not checked, so a typo such as 5M30S without the PT prefix will pass through unnoticed.
