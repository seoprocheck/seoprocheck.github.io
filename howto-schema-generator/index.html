HowTo Schema Generator

Steps

What it does

This generator turns written steps into HowTo structured data in JSON-LD. You give it a title, a short description, an optional total time and cost, and as many steps as you need. It builds a schema.org HowTo object with a numbered HowToStep for each filled-in step and wraps it in a <script type="application/ld+json"> block ready to paste. Nothing you type leaves your browser.

How to use it

  1. Put the guide's name in "Title (How to...)" and a one or two sentence summary in "Description".
  2. Optionally fill in "Total Time" as an ISO 8601 duration (PT30M means 30 minutes, PT1H15M means one hour 15 minutes) and a plain number in "Estimated Cost", with its three-letter code in "Currency".
  3. Give Step 1 a short name and write its instructions below. Click "+ Add Step" for each step after that.
  4. Click "Generate Schema", read through the output, then click "Copy JSON-LD" to copy the whole block, script tags included.

Before you paste it into your site

The tool does not validate your input, so check the output yourself. Blank title or description boxes are left out of the markup without any warning, so fill in both. Total Time is copied exactly as typed, so "30 minutes" gives an invalid value. Currency defaults to USD and is not checked against the list of real codes, and the cost itself should be digits only, without symbols. A step with both boxes blank is skipped, and the filled steps are numbered 1, 2, 3 in order, so an empty box costs nothing. There is no delete button; just leave spare boxes empty.

Google stopped showing HowTo rich results in 2023, so this markup will not bring back a step-by-step display in Google results. The schema.org type is still valid for any parser that reads it, and the usual structured data rule holds: mark up only steps that readers can see on the page, and run the finished page through a validator before you publish.
