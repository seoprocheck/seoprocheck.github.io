LLMs.txt Generator

Create an llms.txt file to help AI systems understand your site. Learn more

What it does

This tool assembles a basic llms.txt file from five fields. The output is plain Markdown: your site name as an H1 heading, your description as a blockquote, then optional "Topics", "Important Pages" and "Contact" sections written as bullet lists. You can copy the text or download it as a file named llms.txt. It runs in your browser and never contacts your site.

How to use it

  1. Type your site's name into Site Name. It becomes the H1 line, which is the one element the llms.txt proposal requires.
  2. Write one or two plain sentences in Site Description saying what the site covers and who it is for.
  3. Add a few subjects to Key Topics, separated by commas. Each one becomes its own bullet.
  4. List your most useful pages in Important Pages, one full URL per line. Add a Contact Email if you want one listed.
  5. Click "Generate llms.txt", read the result, then use Copy or Download and upload the file to the root of your site so it answers at /llms.txt.

Before you publish it

The generator is deliberately simple. It does not check that fields are filled in, so an empty name produces a heading with nothing after it. It also lists your pages as bare URLs. The proposal at llmstxt.org describes each entry as a Markdown link with a short note, such as "- [Pricing](https://example.com/pricing): plans and limits", so it is worth editing each line into that form by hand. The proposal does not define Topics or Contact sections; they are extras this tool adds.

Keep expectations honest, too. llms.txt is a community proposal, and no major AI search or answer engine has shown that it fetches the file or uses it. Publish it as cheap housekeeping if you like, but do not count on it to change how AI tools see your site.
