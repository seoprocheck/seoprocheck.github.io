What these schema generators do

Structured data tells search engines what a page is: an article, a product, an event, a video. Each generator on this page turns a short form into JSON-LD, the format Google recommends, wrapped in a script tag you can paste into your page. You fill in the fields, click Generate Schema and copy the result. Nothing you type leaves your browser.

Which tool for which job

  • Schema Markup Generator: the general option for Article, Product, Local Business, Organization, Person and WebPage markup.
  • FAQ Schema Generator: a page with a real list of questions and answers that visitors can read.
  • HowTo Schema Generator: step-by-step instructions, with an optional total time and cost.
  • Breadcrumb Schema Generator: the path from your home page to the current page, one level at a time.
  • Video Schema Generator: a page built around a video, with its thumbnail, upload date and duration.
  • Event Schema Generator: concerts, classes and conferences with dates, a venue, status, in-person or online attendance, organizer and ticket offers.

Before you publish, run the output through Google's Rich Results Test and make sure every value matches what visitors can see on the page. The Schema Markup Generator leaves out any field you leave blank, including the Article publisher, so fill in every value you have. Durations use the ISO 8601 format shown in the fields, such as PT30M for 30 minutes. A page can carry more than one block, so for an article with breadcrumbs, generate both and paste them side by side. If a hand edit breaks the output, paste the JSON between the script tags into the JSON Validator & Formatter to find the problem.

If your markup validates but no rich result appears, read How to Validate and Debug Structured Data When Rich Results Fail to Show.
